# Proposal: Time Tracking MVP

## Why

Planix users need to estimate task effort and log actual time spent. This enables project capacity planning, billing accuracy, and retrospective analysis. Time tracking is the #1 requested feature by development teams using kanban boards.

## What

Add time tracking to Planix:
- Set time estimates on tasks (displayed on kanban cards)
- Log time entries against tasks (multiple entries per task)
- View personal timesheet (daily/weekly)
- See estimated vs actual time on task detail page

## Scope

**In scope:** Manual time entry, estimates, personal timesheet view, task-level time summary.

**Out of scope (V1):** Live timer, billing rates, project-level time reports, time approval workflows.

## Success Criteria

- Users can set estimates on tasks and see them on kanban cards
- Users can log time entries with duration, date, and description
- Users can view their personal timesheet grouped by day
- Task detail shows estimated vs logged time with progress indicator
