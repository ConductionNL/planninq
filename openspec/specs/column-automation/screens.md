# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- PlBord https://identity.conduction.nl/screens/board?id=planninq/PlBord
- PlFlows: the flows overview and the chosen flow in list mode: when, if, then, with an administrators only step; variant of the canonical set, imports OrFlowOverzichtTabel, OrFlowKop, OrFlowStappenlijst, OrFlowStap https://identity.conduction.nl/screens/board?id=planninq/PlFlows
- openregister/OrFlowLijst: the canonical list mode this variant follows https://identity.conduction.nl/screens/board?id=openregister/OrFlowLijst
